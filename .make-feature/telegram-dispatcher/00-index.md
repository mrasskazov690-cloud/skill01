# Контекст функции

Исходный запрос: [01-request.md](01-request.md)

Цель: система, которая принимает заявки из Telegram (аренда жилья, до 500 сообщений в день), сохраняет их в PostgreSQL, распределяет между 2–3 операторами, отправляет утверждённые шаблоны с подтверждением через API и даёт ограниченное управление через собственный MCP.
Текущий этап: **закрыт**. Этапы ТЗ 1–2 выполнены; владелец ответил на Q1–Q8 (см. [../telegram-core/01-request.md](../telegram-core/01-request.md)). Продолжение — запуск [../telegram-core/00-index.md](../telegram-core/00-index.md).
Режим: **deep**. Причина: отправка сообщений реальным клиентам необратима, есть персональные данные, Telegram-сессии дают полный доступ к аккаунтам, ключевая интеграция (Business/MTProto) не проверена.
Предел: 12 делегаций, 2 исправления, 45 минут на запуск. Пользователь меньший предел не задавал.
Разрешения: локальная разработка и тесты. **Запрещено без явного согласия:** отправка реальных сообщений, production-автоматизация, публикация.
Реальные процессы и агенты: оркестратор (эта сессия). Делегаций пока нет.
